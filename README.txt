AW119 POWER ASSURANCE CHECK — PWA CALIBRADA

Esta versão usa calibração geométrica das curvas vetoriais extraídas diretamente das Figuras 4-5 (Hover), 4-6 (130 KIAS) e 4-7 (100 KIAS) do AW119 MKII G1000H RFM fornecido.

O cálculo interpola somente entre as linhas efetivamente existentes no nomograma. Não extrapola além da escala do gráfico.

IMPORTANTE: esta ferramenta é auxiliar e NÃO substitui o RFM/Flight Manual aprovado. Confirme a leitura diretamente no gráfico antes de qualquer decisão operacional ou de aeronavegabilidade.

Para usar como app no iPhone:
1) Hospede os arquivos desta pasta em um endereço HTTPS (por exemplo, GitHub Pages).
2) Abra o endereço no Safari.
3) Compartilhar -> Adicionar à Tela de Início -> abrir como app da web.

Arquivos principais:
- index.html
- manifest.webmanifest
- sw.js
- apple-touch-icon.png
- figure_4-5_hover.png
- figure_4-6_130kt.png
- figure_4-7_100kt.png
