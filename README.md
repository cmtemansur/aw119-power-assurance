# AW119 Power Assurance Check

Ferramenta auxiliar para leitura das Figuras 4-5, 4-6 e 4-7 do AW119 MKII G1000H RFM.

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `aw119-power-assurance`.
2. Envie **todos os arquivos desta pasta para a raiz do repositório**.
3. Confirme que `index.html` está na raiz.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Branch: `main`; pasta: `/ (root)`; clique em **Save**.
7. Aguarde a publicação e abra a URL informada pelo GitHub Pages.

O GitHub Pages procura `index.html` como arquivo de entrada quando ele está na raiz da fonte publicada.

## No iPhone

Abra a URL publicada no Safari → Compartilhar → **Adicionar à Tela de Início** → ative **Abrir como App**, quando essa opção estiver disponível.

## Importante

Esta é uma ferramenta auxiliar. Não substitui o RFM/Flight Manual aprovado e não deve ser usada como única fonte para decisão operacional ou de aeronavegabilidade. Em caso de divergência, dúvida ou resultado inesperado, prevalece o manual oficial aplicável à aeronave.
